# Drowsy.Games

A compact index of three Warhammer Fantasy campaigns and tools.

Edit the title, links, and descriptions directly in `index.html`. Styles live in the same file. There are no dependencies, build step, external assets, or JavaScript.

GitHub Pages publishes `main` from the repository root. Until the apex DNS cutover, use https://jeremyglebe.github.io/site.drowsy.games/ (GitHub may redirect it through the existing user-site domain to https://jeremyglebe.com/site.drowsy.games/).

See `DNS-CUTOVER.md` for the pending custom-domain setup. This repository does not change the user-site repository or its `jeremyglebe.com` domain.
